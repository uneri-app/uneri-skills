# Security policy

uneri-skills is a set of Markdown skills and two small hooks. It reads and writes local files, and `issue-upsert` and `pr-upsert` call `gh` after you confirm the exact commands.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: on the repository's **Security** tab, choose **Report a vulnerability**.

Include the version (`plugin.json`), what you did, and what happened. We will reply there.

## Supported versions

Only the latest release is supported while the plugin is in 0.x.
