# Architecture Decision Records

Decisions that outlive a single spec, with the reasons and trade-offs behind them. The spec holds how something is
built; an ADR holds why it was chosen. Decisions are not rewritten: a changed decision is a new ADR that supersedes
the old one.

Status is one of `proposed`, `accepted`, `rejected`, `deprecated`, `superseded`, `partially-superseded`.
