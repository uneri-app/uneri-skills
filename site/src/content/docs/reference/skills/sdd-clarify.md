Use after requirements are approved and before design — surfaces ambiguities as structured questions and records the answers in the requirements' Clarifications section. Mandatory gate before `/uneri-skills:sdd-design` (records "No open questions" when there are none). Local-only. Triggers include "clarify requirements", "曖昧点を潰す", "spec clarify". Output language follows `spec.json`.

## 使い方

```text
/uneri-skills:sdd-clarify
```
