Conventions for authoring uneri use cases — the UC-ID system, notation, and granularity rules that keep `.kiro/uneri/use-cases.md` consistent. Auto-loads whenever use cases are being written or edited (editing `use-cases.md`, adding/renaming/retiring a UC, discussing UC-IDs, actors, realizes/aggregates, or "ユースケースを書く/直す"). Knowledge skill — not a command, takes no arguments; it supplies the shared rules that uneri-skills:udd-init / uneri-skills:udd-add / uneri-skills:udd-validate / uneri-skills:sdd-init build on.

## 使い方

```text
/uneri-skills:udd-authoring
```
