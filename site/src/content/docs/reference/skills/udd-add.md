Use when adding a new use case to an existing `.kiro/uneri/use-cases.md` — appends one `UC-{CTX}-NNN` entry with auto-numbering, a validated `actor`, and optional `realizes`/`aggregates`. Triggers include "add a use case", "新しいユースケースを追加", "UCを追記", or after uneri-skills:udd-init when the list needs entries. NOT for creating the file (use uneri-skills:udd-init) or for non-functional requirements (those go to steering/spec). Output language follows `.uneri.json`.

## 使い方

```text
/uneri-skills:udd-add
```
