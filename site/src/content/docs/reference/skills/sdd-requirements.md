Use after `/uneri-skills:sdd-init` to generate EARS requirements for a spec, auto-seeded from the traced use case's sunny-day and rainy-day scenarios. Refuses to run until the spec exists. Local-only. Triggers include "generate requirements", "requirements を作る", "spec requirements". Output language follows `.uneri.json` / `spec.json`.

## 使い方

```text
/uneri-skills:sdd-requirements
```
