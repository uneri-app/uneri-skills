Implement approved tasks using TDD with native subagent dispatch. Runs all pending tasks autonomously to the end, or selected tasks manually. Refuses to start until the spec's tasks are approved. Triggers include "implement this spec", "タスクを実装して", "実装を進めて", "spec impl". Takes `{feature-name} [task-numbers]`.
