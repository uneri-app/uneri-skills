---
title: Quick start
description: Go from UDD to an SDD implementation in one pass.
---

1. `/uneri-skills:udd-init`: choose the language, map the domain, and create `.kiro/uneri/use-cases.md`.
2. `/uneri-skills:udd-add`: add use cases one at a time.
3. `/uneri-skills:sdd-init`: turn a use case into a spec (`.kiro/specs/<NNN-slug>/`).
4. `/uneri-skills:sdd-requirements` → `/uneri-skills:sdd-clarify` → `/uneri-skills:sdd-design` → `/uneri-skills:sdd-tasks`: requirements, clarification, design, and task breakdown.
5. `/uneri-skills:sdd-impl`: implement the approved tasks.
6. `/uneri-skills:sdd-validate-impl`: check cross-task consistency and run the tests.
7. `/uneri-skills:pr-upsert`: open a labelled pull request.

See the [skills reference](../../reference/skills/) for each skill, and the [practical manual](../../guides/manual/) for a worked example.
