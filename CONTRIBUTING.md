# Contributing

uneri-skills is a public beta (0.x). The file formats (`use-cases.md`, `spec.json`) are kept compatible; the wording and steps of the skills may still change. Reports of where it breaks are the most useful thing you can send.

## Where each request goes

| You have                            | Go to                                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------------------------- |
| A bug in a skill or a hook          | [Bug issue](https://github.com/uneri-app/uneri-skills/issues/new?template=bug.yml)           |
| A change to an existing skill       | [Change issue](https://github.com/uneri-app/uneri-skills/issues/new?template=change.yml)     |
| A question, or "how do I...?"       | [Discussions: Q&A](https://github.com/uneri-app/uneri-skills/discussions/categories/q-a)     |
| An idea for a new skill or workflow | [Discussions: Ideas](https://github.com/uneri-app/uneri-skills/discussions/categories/ideas) |
| A security problem                  | See [SECURITY.md](SECURITY.md). Do not open a public issue.                                  |

Pull requests are open to collaborators only, so describe the fix in an issue instead.
This repository is a snapshot published from a private development repository; a change merged here would be overwritten by the next release, so changes are made there.

## Issues written with an AI agent

Agents are welcome to help, but you post the issue, so you own it:

- **One problem per issue.** Several findings from one session are several issues, or none.
- **Short.** If it does not fit on one screen, cut it.
- **Repro first.** The steps that show the problem come before any analysis.
- **No pasted specs.** No full proposals, plans or rewritten `SKILL.md` files. Describe the problem.
